# Spotify Clone

A Spotify Clone built as a project using **HTML** and **CSS**.

## Overview

This project is a front-end recreation of Spotify’s interface and core music player experience. It focuses on building a responsive and interactive UI that resembles the look and feel of the Spotify web app.

## Features

- Clean and modern Spotify-inspired UI
- Responsive layout
- Playlist and music player sections
- Play/pause controls
- Track progress display
- Built with HTML and CSS

## Tech Stack

- **HTML** — 73.5%
- **CSS** — 26.5%

## Getting Started

### Prerequisites
- A modern web browser

### Installation

```bash
git clone https://github.com/KaranSaini-Git/Spotify.git
cd Spotify
```

### Run the project

Open the `index.html` file in your browser.

You can also use a local development server, such as:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```
